# Cockpit Drone - Система управления, телеметрии и симуляции

Полнофункциональный программный комплекс на Object Pascal (Lazarus / Free Pascal) для дистанционного управления, приема телеметрии и физической 3D-симуляции беспилотных летательных аппаратов (БПЛА). Включает поддержку аналоговых джойстиков, GPS-приемников, видеотрансляций (H.264 и синтетическая камера симулятора), тактических карт OpenStreetMap и сетевого мультиплеера.

## Обзор проекта

Архитектура **Cockpit Drone** разделяет графический интерфейс пользователя и критически важный поток обмена данными: отправка команд полета (каждые 50 мс) и прием телеметрии выполняются в выделенном потоке и не блокируются окнами UI.

Основные возможности:
- **Надежность и безопасность:** Аварийное отключение моторов клавишей «Пробел» и плавный возврат в режим висения.
- **Тактический интерфейс:** Приборная панель, светодиоды статуса, военный проекционный дисплей (HUD), карта полета и видео с низкой задержкой.
- **Комплексная экосистема:** Включает автономный **3D-симулятор** (`simulador/simulador.exe`) с 6DOF динамикой и сервер мультиплеера на PHP/WebSocket (`PHP/`).

## 3D-симулятор и Мультиплеер

> **ПОДКЛЮЧЕНИЕ К МУЛЬТИПЛЕЕРУ:**  
> Подключение к **Общему миру** выполняется через **Симулятор** (`simulador.exe`):  
> 1. Откройте `simulador.exe`.  
> 2. В панели **Общий мир** укажите адрес сервера (`https://maurinsoft.com.br/cockpit/`) и ваш позывной, затем нажмите **Войти**.  
> 3. Дроны в радиусе **2 км** отобразятся на тактической карте и в камере.  
> 4. Программа **Cockpit Drone** (`drone.exe`) подключается локально по адресу `127.0.0.1`.

## Загрузка скомпилированных файлов

Готовые исполняемые файлы находятся в папке [`bin/`](bin/):
- **`bin/setup_cockpit_drone_0.41.exe`:** Полный инсталлятор для Windows.
- **`bin/drone.exe`:** Исполняемый файл Cockpit Drone.
- **`bin/simulador.exe`:** Исполняемый файл 3D-симулятора.
